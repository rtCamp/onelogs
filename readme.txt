OneLogs extends the Stream plugin to provide a centralized, network-level dashboard for viewing and managing activity logs across multisite or OnePress installations.

== Description ==

OneLogs extends the capabilities of the Stream plugin by providing a centralized interface for viewing and managing logs across multiple connected sites. Built on the OnePress Framework, it aggregates site activity for unified visibility, governance, and auditing across a network.

== Installation ==

1. Download the OneLogs plugin ZIP from the latest GitHub release and install it on your WordPress sites.
2. Ensure the Stream plugin is installed and active on every site you want to monitor.
3. Activate OneLogs on the site(s); for multisite installations, Network Activate.
4. On the Governing Site, go to Dashboard → OneLogs → Settings and register each Brand Site with its name, URL, and API key.

== Frequently Asked Questions ==

Q: Does OneLogs replace Stream?
A: No — OneLogs extends Stream. Stream must remain active for OneLogs to work.

Q: What filters are supported?
A: You can filter logs by `Site`, `User`, `Context`, `Action`, and `Date Range`.

Q: What fields are searched?
A: The search field searches within the `Summary` column of logged events.

Q: Can I export logs?
A: Yes — filtered or complete log datasets can be exported to CSV from the dashboard.
